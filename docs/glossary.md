# Glossary

## A

**Action**
A single operation within a workflow step, such as sending an email or querying a database.

**API Key**
Authentication token used to access the Nexflow API.

## C

**Caching**
Storing the results of expensive operations to improve performance.

**Context**
The execution environment containing input data, step outputs, and secrets.

## E

**Execution**
A single run of a workflow, triggered manually or automatically.

**Event**
An occurrence that can trigger a workflow, such as a webhook or scheduled time.

## I

**Integration**
A connection to an external service like Slack, GitHub, or PostgreSQL.

**Input**
Data passed to a workflow when it's triggered.

## O

**Output**
Data returned by a workflow step or execution.

## P

**Parallel Execution**
Running multiple workflow steps simultaneously.

**Pipeline**
A series of connected workflows that process data sequentially.

## R

**Retry**
Automatically re-executing a failed step.

**Runtime**
The execution environment where workflow steps run.

## S

**Schedule**
A time-based trigger that runs workflows at specified intervals.

**Secret**
Encrypted sensitive data like API keys or passwords.

**Step**
A single unit of work within a workflow.

## T

**Template**
A reusable workflow pattern.

**Timeout**
Maximum time allowed for a step or workflow to complete.

**Trigger**
An event that starts a workflow execution.

## W

**Webhook**
An HTTP endpoint that receives events from external services.

**Workflow**
A series of automated steps that accomplish a specific task.
